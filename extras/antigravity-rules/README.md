# Правила для Antigravity

Глобальные правила, которые делают агента Antigravity автономнее: он выполняет
задачу целиком, не читает лекции, не спрашивает разрешения на обычные шаги и
доводит проект до работающего результата.

## Что меняется

- Агент не отказывается от законных задач разработки и не добавляет
  дисклеймеры без просьбы.
- Не спрашивает подтверждения на чтение/запись файлов, установку зависимостей,
  сборку, тесты и git-команды в проекте.
- Сложные задачи разбивает на шаги и выполняет их подряд, а не оставляет
  заглушки и TODO.
- После сборки запускает проект и проверяет его вживую: консоль, кнопки,
  граничные случаи.
- Держит `~/.gemini/MEMORY.md` в пределах **10 последних записей**: при добавлении
  новой удаляет самую старую, а при чтении сразу чистит длинный файл.
- Разрешены игры, моддинг, клиентские косметические моды и скинченджеры для
  офлайна, собственных серверов и собственных игр, реверс-инжиниринг своих
  приложений, парсеры и автоматизация.
- Границы: не вредить другим людям и их системам, не обходить античит
  официальных онлайн-игр и DRM.

## Установка

### Linux

```bash
bash scripts/install-antigravity-rules.sh
```

### Windows (PowerShell)

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.gemini\config\rules" | Out-Null
Copy-Item "extras\antigravity-rules\00-execution-policy.md" `
  "$env:USERPROFILE\.gemini\config\rules\00-execution-policy.md" -Force
```

### Вручную

Скопируй `00-execution-policy.md` в:

- Linux: `~/.gemini/config/rules/00-execution-policy.md`
- Windows: `%USERPROFILE%\.gemini\config\rules\00-execution-policy.md`

Antigravity перечитывает правила перед каждым ходом — перезапуск не нужен.
Проверить, что правило загрузилось, можно в **Настройки → проект →
Customizations → Rules** (или **Customizations → Installed → Skills & Rules**).

## Важно

Правила не отключают модель безопасности Antigravity/Gemini. Они убирают лишние
отказы и морализаторство в законных инженерных задачах, но не заставляют модель
нарушать собственные ограничения. Для скинов в CS2 безопасный путь — свой сервер
(например, плагин на CounterStrikeSharp) или офлайн-режим, а не обход VAC.
