# Янтарь (Amber AG)

**Готовый русский Google Antigravity одной кнопкой.**

`Янтарь` — это переносной лаунчер, который:

1. при первом запуске скачивает и устанавливает **официальный** Google Antigravity;
2. включает **русский интерфейс** (публичный словарь сообщества, без изменения файлов приложения);
3. поднимает локальный гейт-прокси с публичными настройками DNS-AI, чтобы Antigravity работал из России;
4. сохраняет всё в пользовательской папке и не требует прав администратора на Linux.

## Важно

- В состав **не входят** аккаунты, VPN-конфиги, токены, ключи и любые пользовательские данные.
- Готовые файлы выпускаются только с публичными компонентами: словарём перевода, кодом лаунчера и открытыми адресами DNS-AI из публичного канала.
- Antigravity скачивается с официального сайта при первом запуске. Для входа нужен твой Google-аккаунт.
- Проект неофициальный; использование может нарушать условия обслуживания Google. Используй на свой страх и риск.

## Готовые сборки

В разделе [Releases](../../releases):

| Файл | Система |
| --- | --- |
| `AmberAG.exe` | Windows 10/11 x86_64 |
| `AmberAG-x86_64.AppImage` | Linux x86_64 |

### Linux

```bash
chmod +x AmberAG-x86_64.AppImage
./AmberAG-x86_64.AppImage
```

### Windows

Запусти `AmberAG.exe`. Распаковка идёт во временную папку, затем лаунчер копирует себя в
`%LOCALAPPDATA%\AmberAG` и скачивает официальный установщик Antigravity.

## Как это работает

- интерфейс переводится через локальный CDP-порт: в окна внедряется JS-оверлей со словарём (~600 фраз);
- файлы самого Antigravity не изменяются, оригинальный английский лаунчер остаётся доступен;
- для обхода регионального ограничения используется локальный CONNECT-прокси на `127.0.0.1:53190`
  и публичные SNI-адреса DNS-AI; при необходимости создаётся локальный CA (закрытый ключ лежит
  только в пакете и никуда не отправляется).

## Правила для Antigravity (опционально)

В `extras/antigravity-rules/` лежит глобальное правило, которое делает агента
Antigravity автономнее: без лишних отказов и лекций, с полным циклом
«код → сборка → запуск → проверка». Установка на Linux:

```bash
bash scripts/install-antigravity-rules.sh
```

Версия для Windows и описание границ — в `extras/antigravity-rules/README.md`.

## Сборка из исходников

Нужны `curl`, `tar`, `7z`, `python3`, `appimagetool`. Скрипт `scripts/build.sh` скачивает
портативный Python, собирает Windows SFX и Linux AppImage в папку `packages/`.
